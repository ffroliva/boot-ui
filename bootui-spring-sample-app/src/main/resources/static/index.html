Spring Boot 4 demo

Welcome to the BootUI sample app

This app demonstrates a small Spring Boot service with public endpoints, secured admin routes, scheduled work, JPA data, and enough runtime state for BootUI to inspect.

Open BootUI

Sample action lab

Run a few safe requests to generate data for BootUI panels. Then open the linked panels to see how BootUI explains the same app from different angles.

Calls GET /api/sample/products to exercise Spring Data, cache, and HTTP Exchanges.

Inspect: Spring Data, Cache, HTTP Exchanges

Upserts three synthetic documents and runs bounded repository queries. Requires run-local-mongodb.sh.

In this profile: Mongo stores documents; H2 backs JPA, Flyway, Liquibase and SQL Trace. Inspect: MongoDB, Spring Data

Calls GET /api/sample/product-search to run a live, uncached SQL SELECT.

Inspect: SQL Trace, Spring Data

Loads one entity twice in separate persistence contexts to produce a cache miss, put, and hit.

Inspect: Hibernate Statistics

Creates committed, slow, rolled-back, and nested transaction boundaries in one safe request.

Inspect: Transactions

Calls GET /api/sample/fault-tolerance/retry, which fails once and then recovers through Spring Retry.

Inspect: Fault Tolerance, Live Activity

Calls GET /api/sample/fault-tolerance/circuit-breaker to open the sample Resilience4j breaker.

Inspect: Fault Tolerance, Live Activity

Adds demo attributes, including a fake token, to this browser session.

Inspect: HTTP Sessions

Calls GET /api/sample/hello so BootUI can show configuration-backed behavior.

Inspect: Configuration, Cache, HTTP Probe

Calls GET /api/hello as a simple public endpoint for mappings and probes.

Inspect: Mappings, HTTP Probe, HTTP Exchanges

Opens /echo, sends one text message, and waits for the echoed response.

Inspect: WebSockets → Endpoints and Sessions

Subscribes to /topic/chat and sends one message to /app/chat.

Inspect: WebSockets → Subscriptions and Activity

Calls GET /api/secure with admin/admin credentials.

Inspect: Spring Security, Security Logs

Calls GET /api/secure/products with admin/admin to run a secured, SQL-backed request.

Inspect: Live Activity, Spring Security, SQL Trace

Calls the same secured endpoint with developer/developer to produce a forbidden response.

Inspect: Spring Security, Security Logs, Pentesting

Calls GET /api/sample/boom, which throws on purpose to record a server-side failure.

Inspect: Exceptions, Log Tail, Traces

Calls GET /api/sample/metrics-burst to record a custom counter and timer several times.

Inspect: Metrics

Calls GET /api/sample/allocate to briefly allocate a bounded heap buffer.

Inspect: Live Memory, Heap Dump, JVM Tuning

Calls GET /api/sample/slow, which sleeps briefly so a request thread stays busy.

Inspect: Threads, Metrics, HTTP Exchanges

Calls GET /api/sample/pool-stress to run several concurrent read-only queries.

Inspect: Database Connection Pools, Spring Data, SQL Trace

Calls GET /api/sample/chained, which nests spans across a catalog read and a live query.

Inspect: Traces, Diagnostics, HTTP Exchanges, SQL Trace

Calls GET /api/sample/send-email to send a demo email through the app's mail sender.

Inspect: Email

Calls GET /api/sample/send-kafka-message to publish a demo "order created" event.

Inspect: Kafka (requires the "docker" profile)

Calls GET /api/sample/quarkus-secure-products, which this Spring Boot app uses to call the companion Quarkus sample app's own secured, SQL-backed GET /api/secure/products (admin/admin) over HTTP.

Inspect: Traces (here, for the merged waterfall), SQL Trace and Spring Security on the Quarkus app

Calls GET /api/secure with bad credentials to produce an unauthorized response.

Inspect: Spring Security, Security Logs, Pentesting
